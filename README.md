# SAMARKAND

Роглайт-экшн, где ты — чудовище. Каждая комната это человеческое поселение: хутор,
деревня, острог, скит. Комната считается пройденной, когда в ней не остаётся живых.
После каждой зачистки — выбор навыка, а на ключевых этапах — необратимая мутация,
которая меняет и характеристики, и то, как монстр выглядит.

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Открыть http://localhost:5173

Сборка: `npm run build` (выход в `dist/`, ~98 КБ gzip, без внешних ассетов).

## Проверки

```bash
npm run check
```

Это типы, линтер и тесты одной командой; по отдельности — `npm run typecheck`,
`npm run lint`, `npm test` (и `npm run test:watch` во время работы). То же самое
гоняется в GitHub Actions на каждый push и pull request, плюс сборка, `npm audit` и
отдельная работа на каждый браузерный движок.

Тесты покрывают то, где ошибка молчит, а не падает: модель урона (броня трогает только
физический, сопротивления — свой элемент, ничто не даёт полного иммунитета), детерминизм
ГПСЧ и независимость его форков, инварианты карты забега (нет тупиков, нет недостижимых
остановок, рёбра не перескакивают полосу), паритет ключей в трёх словарях, миграции
сохранений с возвратом душ, потолки и полы характеристик, целостность таблиц контента,
разбор настроек из битого сохранения и логика переназначения клавиш.
Всё это чистые функции — DOM не нужен, и прогон занимает пару секунд.

### Браузеры

```bash
npm run test:e2e
```

Playwright гоняет игру в трёх движках — Chromium, Firefox и WebKit (он же Safari) — на
шести разрешениях от 400×400 до 1920×1080. Часть прогонов идёт по **собранному** бандлу,
как у игрока: грузится, рисует, не молчит в консоль, переживает изменение размера окна,
поднимает звук по первому клику. Часть — по dev-серверу, где есть отладочная ручка:
зачистка поселения от начала до конца, одинаковый забег из одного сида в каждом движке,
монстр действительно нарисован, и замер стоимости кадра в самой тяжёлой арене.

Стоимость кадра, 17 защитников, двенадцатая глубина (медиана из 150 кадров):

| движок | медиана | p95 |
|---|---|---|
| Chromium | 0.4 мс | 0.6 мс |
| Firefox | 2 мс | 4 мс |
| WebKit (Playwright, Windows) | 26 мс | 29 мс |

Бюджет кадра при 60 Гц — 16.7 мс. Цифра WebKit не про Safari: сборка Playwright вне
macOS растеризует канвас программно; она измеряется и печатается, но порог на неё не
ставится.

Чего тесты не проверяют: как игра ощущается, и как она выглядит. Для этого автопрогон
из раздела «Отладка» и живая обкатка.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение |
| — | **автоатака по ближайшей цели, в том числе на бегу** |
| Пробел / Shift | рывок (неуязвимость на время рывка) |
| Tab | лист формы: характеристики, стихии, навыки, живая статистика |
| Esc | пауза |
| 1 / 2 / 3 | выбор карты или мутации |

Монстр бьёт сам и не требует остановки. Стоять на месте всё равно выгодно: разброс
снарядов сходится к нулю примерно за четверть секунды, а на бегу веер раскрывается
вдвое. Так бег остаётся полноценной опцией, а не наказанием.

## Системы

**Урон.** Шесть стихий: физический, огонь, яд, мороз, молния, скверна (плюс свет —
оружие жрецов). Каждая гасится отдельно: броня трогает только физический,
сопротивления — свою стихию. Поэтому «собрать огненного монстра» и «собрать
пробитие брони» — это разные билды, а не два способа написать «+урон».

**Статусы.** Горение и яд — урон по времени со стаками; охлаждение замедляет и на
десяти стаках замораживает; разряд и проклятие увеличивают получаемый целью урон;
кровотечение усиливается, если цель бежит; ужас обращает в бегство.

**Карта забега.** Путь — не прямая линия, а слоистый граф на 12 глубин: два-три узла в
слое, рёбра только между соседними полосами, поэтому весь маршрут читается без прокрутки.
Перед каждым шагом выбираешь, куда идти:

| Остановка | Что это |
|---|---|
| **Поселение** | обычная зачистка: души и опыт |
| **Гарнизон** | тесная арена, рыцари и жрецы, **две реликвии гарантированы** |
| **Логово падальщика** | без боя: души в обмен на карту, лечение, +здоровье или снятие порчи |
| **Проклятый алтарь** | сильная карта (не ниже редкой) ценой **постоянного проклятия** |
| **Твердыня** | Инквизитор, конец пути |

Маршрут гарантированно содержит минимум две лавки и две элиты, первые две глубины —
обычные бои, а перед боссом слой всегда чистый. Пройденное перечёркнуто, доступное
пульсирует, дальнее видно приглушённым — планировать на три шага вперёд можно.

**Проклятия.** Десять штук, каждое бьёт по конкретному стилю игры: хрупкие кости режут
здоровье, свинцовые лапы — скорость, дрожь ломает точность, голодная тьма замедляет
набор уровней. Вопрос не «плохо ли это», а «плохо ли это для моего билда». Видны в листе
формы (Tab), снимаются только в лавке.

**Уровни и навыки.** Каждая душа — это и валюта, и опыт. Как только полоса опыта
заполняется, игра замирает и сразу открывает выбор из трёх карт — награда приходит,
пока убийство, которое её принесло, ещё на экране. Если уровней набралось несколько
подряд, выборы идут один за другим. ~45 карт четырёх редкостей: обычные — чистые числа; редкие меняют
способ доставки урона (стихии, снаряды, рикошеты); эпические добавляют поведение,
которое срабатывает само (взрыв трупов, цепная гроза, чумное облако, выводок);
легендарные определяют билд и обычно чего-то стоят.

**Защитники.** В каждом поселении есть и ближний, и дальний бой, начиная с первой
комнаты. Ополченцы и копейщики идут в клинч и держат дистанцию удара, не залезая в
игрока. Лучники и арбалетчики кайтят и требуют укрытия. Жрецы лечат своих. Баллисты
на башнях простреливают всю карту. Крестьяне разбегаются, выдыхаются и в итоге падают
без сил. Тот, кто долго не может ударить, срывается в отчаянную атаку — комната
никогда не превращается в бесконечную беготню.

**Финал.** Двенадцатая комната достаёт из сида одного из трёх боссов, и это разные бои,
а не разные полоски здоровья. **Инквизитор** держит дистанцию: кольца святых болтов с
просветом, отложенное освящение земли, подкрепления из ополчения и лучников.
**Воевода** давит вплотную — телеграфированный прыжок с обвалом, ударная волна по
земле, двое рыцарей-телохранителей; сопротивляется физическому урону и холоду.
**Огнедержица** отбирает пространство: стена огня, веер углей, кольцо костров вокруг
себя; почти неуязвима к огню, зато хрупкая. Имя арены меняется вместе с боссом.

**Эволюция.** После комнат 4, 8 и 12 — выбор из трёх мутаций. Рога, крылья, лишние
глаза, шипы, элементальные ядра. Монстр рисуется целиком процедурно из описания тела
(`MonsterBody`), поэтому каждая мутация реально меняет силуэт — спрайтов нет.

**Временные облики.** В каждом поселении лежит хотя бы одна реликвия; ещё их роняют
рыцари, жрецы и разрушенные часовни. Подобрал — и на 15–20 секунд становишься другим
существом. Десять форм, и каждая перестраивает тело, а не только цифры:

| Облик | Что видно | Что даёт |
|---|---|---|
| Пламенный облик | огненная аура, тело светится | урон обращается в огонь, земля тлеет |
| Исполин | раздувается в 1.65 раза | +50% здоровья, +35% урона, тяжелее шаг |
| Бесплотность | тело просвечивает, съёживается | +35% уклонения, +40% скорости, хрупче |
| Грозовой венец | рога, жёлтое свечение | цепные молнии, +25% скорости атаки |
| Костяной доспех | дюжина шипов по спине | +70 брони, шипы отражают урон |
| Тысячеокий | десять глаз по телу | +30% крита, наведение снарядов |
| Крылатый ужас | разворачиваются крылья | +30% скорости, +2 рывка |
| Чумное дыхание | зелёная аура, тело пухнет | яд, облака заразы с трупов |
| Рой | распадается на множество лап | +45% скорости атаки, лишний снаряд |
| Ледяное сердце | синеет и покрывается льдом | мороз, ледяная вспышка при рывке |

Формы складываются: можно ходить исполином в огне одновременно. Таймеры видны внизу
экрана. Технически облик — это функция, правящая копию `MonsterBody`; и рендер, и
радиус столкновений берутся из неё, так что исполин действительно занимает больше
места, а не просто рисуется крупнее.

**Стартовое тело.** Забег начинается в одном из четырёх тел, и выбирается оно в логове,
до вылазки. Тело меняет **базовые** статы, а не модификаторы, — поэтому проценты, набранные
за забег, множатся на него, а не топят его собой. **Отродье** ровное во всём. **Ловчий**
быстрый и хрупкий, с двумя рывками и короткой дистанцией. **Исполин** медленный, бронированный,
бьёт редко и тяжело. **Вестник** стреляет парой снарядов, половина урона обращается в
нечестивый, но разлёт широкий и здоровья мало. Отродье и Ловчий доступны сразу, остальные
покупаются за души. Каждое тело — своя процедурная внешность, и в логове она рисуется живьём,
включая запертые: увидеть тварь — и есть причина её захотеть.

**Настройки.** Открываются из меню и из паузы — потому что убавить тряску камеры
хочется обычно уже посреди первого боя, а не до него. Тряска (нет / слабая / полная),
плотность частиц, числа урона, счётчик миллисекунд на кадр, язык, громкость и
переназначение семи клавиш. Язык переехал сюда с главного экрана: три двухбуквенные
плашки в углу легко было не заметить, а «DE» ничего не говорит тому, кто не знает,
что ищет. Список во всю ширину называет каждый язык на нём самом. Всё применяется и сохраняется сразу, кнопки «применить» нет. Ничего из
этого не меняет сложность: настройки правят подачу, а не баланс.

**Мета-прогресс.** Души сохраняются между забегами и тратятся в логове на **разблокировку
контента**, а не на проценты. Из 44 карт, 14 мутаций и 10 обликов свободны только
стартовые 20 карт, 9 форм тела, 3 реликвии и 2 тела — остальные 38 позиций выкупаются и лишь
после этого начинают выпадать в забегах. Логово показывает и запертое: знать, что тебя
ждёт, — половина мотивации. Профиль пишется в `localStorage` с миграциями по версиям.

**Звук.** Полностью процедурный, как и графика: ни одного файла, всё синтезируется
осцилляторами и фильтрованным шумом в момент воспроизведения. Около тридцати звуков —
удары, смерти, обвалы, стихии, интерфейс, — плюс адаптивная подложка из трёх слоёв:
басовый дрон, пэд, открывающийся по мере накала боя, и сердцебиение, слышное только
когда до смерти рукой подать. Мир звучит позиционно: дальние события тише и панорамируются.

Отдельно стоит замах врага — восходящий тон перед ударом. Это единственное, что
позволяет увернуться от того, кого не видно на экране.

Технически: голоса ограничены бюджетом (36 одновременно), одинаковые звуки в одном
кадре схлопываются в один, а на выходе стоит лимитер — двадцать взрывов разом дают пик
0.83 из 1.0 без клиппинга. Громкость настраивается в меню и хранится в профиле.

**Границы.** Арена обнесена видимым барьером — валунами, а в укреплённых поселениях и
у собора кладкой с зубцами. Играбельная зона заканчивается там, где начинается камень,
так что край мира — это предмет, а не невидимая линия. Когда поселение падает, к
порталу ведёт цепочка шевронов рядом с монстром и метка на краю экрана.

**Статистика.** Экран итогов показывает всё, что записал трекер: урон по типам и
источникам, график DPS, точность, крит, список жертв, взятые навыки и мутации,
время по комнатам, самые опасные враги. Летопись хранит пожизненные суммы и рекорды.

## Устройство кода

```
src/
  audio/       процедурный синтез: движок, каталог звуков, адаптивный эмбиент
  core/        математика, детерминированный RNG, ввод, камера
  combat/      модель урона и статусов (чистые функции)
  entities/    Entity → Combatant → Monster / Human / Projectile / Building / Pickup
  progression/ характеристики, карты навыков, мутации, облики, мета-прогресс
  world/       World (симуляция одной комнаты) и генератор поселений
  render/      Renderer, процедурная отрисовка монстра, ландшафт, частицы
  ui/          иммедиат-режим виджетов поверх canvas, HUD и экраны
  game.ts      игровой цикл и конечный автомат состояний
```

Симуляция идёт фиксированным шагом 60 Гц независимо от частоты кадров. Сущности
никогда не обращаются друг к другу напрямую — только через `World`, поэтому весь учёт
урона и телеметрия собраны в одном месте.

Комнаты генерируются из сида: `generateRoom(index, total, rng)` полностью описывает
планировку, поэтому забег воспроизводим. Косметическая случайность (частицы, тряска)
идёт из отдельного генератора, чтобы отрисовка не влияла на симуляцию.

## Отладка

В dev-сборке игра доступна как `window.samarkand`:

- `debugSnapshot()` — состояние, позиции, счётчики, список выживших
- `debugFrame(ms)` — прогнать кадр вручную (нужно, когда вкладка скрыта и rAF стоит)
- `debugLoadRoom(n)`, `debugBuff()`, `debugOfferMutations()`, `debugGrantBoon(id)`
- `debugPlaySound(name)` — проиграть один звук из каталога, для настройки

Автопрогон и снимки экрана: `import('/dev/autoplay.js')`, затем `autoplay()`,
`scene(name)`, `shot(name)`. Снимки пишутся в `dev/shots/` через dev-эндпоинт
`/__shot` (только в режиме разработки, в сборку не попадает).

## Оболочка страницы

Интерфейс рисуется на канвасе, поэтому [index.html](index.html) существует не ради
вёрстки, а ради всего, что читает документ, а не картинку: вкладка браузера, превью
ссылки, экранный диктор. Там описание, theme-color, color-scheme, Open Graph и Twitter
Card. Атрибут `lang` выставляется при загрузке и переписывается при смене языка —
диктору нельзя называть русский текст английскими фонемами.

Иконка вкладки тоже процедурная и встроенная: SVG прямо в `data:` URI, так что правило
«ни одного файла ассетов» остаётся в силе, и запросов на один меньше.
